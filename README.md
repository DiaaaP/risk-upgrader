# Risk Upgrader 0.3.0

Отдельный BepInEx-мод для Risk of Rain 2 по мотивам Item Upgrader.

## Установка

Самый простой способ для Windows x64:

1. Скачай `RiskUpgrader-0.3.0-Windows-OneClick.zip` из папки `packages`.
2. Закрой игру и распакуй содержимое архива прямо в корень Risk of Rain 2 рядом с `Risk of Rain 2.exe`.
3. Запусти игру через Steam и нажми `F7` во время забега. Отдельно запускать BepInEx не требуется.

One-click архив уже содержит официальный BepInEx 5.4.23.5. Если BepInEx 5 установлен, можно скачать маленький обычный архив и положить `RiskUpgrader.dll` в `BepInEx/plugins/RiskUpgrader/`.

## Сборка

```powershell
.\build.ps1
.\test.ps1
.\package-oneclick.ps1
```

Для установки локальной сборки закрой игру и запусти `.\build.ps1 -Install`.

- `F7` открывает и закрывает окно; `Esc` также закрывает его.
- Пока окно открыто, локальный игрок-хост получает Hidden Invincibility. После закрытия постоянная защита сменяется коротким выходным щитом; союзников это не затрагивает.
- При закрытии оператор получает ещё 2.25 секунды неуязвимости, а врагов в радиусе 18 метров отталкивает безопасный импульс без урона. Радиус, сила и время меняются в конфиге.
- Слева выбирается предмет из локального инвентаря, справа — цель из доступного каталога текущего забега.
- Формула: `0.9 × (ценность входа × количество) / (ценность цели × количество результата)`, пределы 0.1–90%.
- Быстрые кнопки подбирают число входных стаков для 30%, 50% или 70%.
- Входные предметы снимаются при запуске колеса. При успехе сервер выдаёт цель, при промахе вложение сгорает.
- Первая версия работает в одиночной игре и у хоста. Друзьям мод не требуется, но открыть своё колесо клиент пока не может.
- Тиры Hallowed Concepts поддерживаются: `FoodTier=0.5`, `Hex=4`, `Page=6`, `Cursed=8`. Служебные `NoTier/AssignedAtRuntime` исключены.
- Иконки DLC загружаются через Addressables и появляются в уже открытом окне после завершения загрузки.
- Интерфейс повторяет компоновку оригинального Upgrader: большие карточки входа/цели, колесо, золотая кнопка и сетка настоящих игровых иконок.
- Каталог разбит на страницы по 30 предметов, поэтому окно не создаёт сотни элементов сразу.

Мод меняет инвентарь и рассчитан на одиночную игру либо лобби, участники которого согласны на изменённые правила.
